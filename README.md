# Smart Restaurant Order (Java Console Application)

A Java console program designed to translate real-world restaurant billing logic into clean, structured code[cite: 1]. Developed as an assignment for Java programming.

## Features
- Collects customer details (name, age, meal price, drink count, student status, and service rating).
- Calculates drink costs at a fixed rate ($15.50 per drink)[cite: 1].
- Evaluates and applies the larger of applicable discounts (10% student discount or 5% senior discount for ages 60+)[cite: 1].
- Computes a 10% tip for service ratings of 4 or 5, with built-in validation for ratings outside the 1–5 range[cite: 1].
- Type-casts the final bill into an integer to display the whole amount without cents[cite: 1].
- Prints an itemized receipt layout[cite: 1].

## Requirements Met
- Uses variables, constants, `Scanner` for keyboard input, and arithmetic calculations[cite: 1].
- Implements explicit type casting and conditional logic (`if`, `else if`, `else`)[cite: 1].
- Clean separation of concerns without using loops, arrays, or extra methods[cite: 1].
